# How to stake 0xAssets

Staking 0xAssets allows holders to earn protocol-generated rewards and participate in yield strategies powered by the ORBT ecosystem.

Through the staking process, users can deposit 0xAssets (e.g., 0xUSD, 0xETH, or 0xBTC) into designated staking modules to receive yield-bearing counterparts such as s0xUSD, s0xETH, or s0xBTC.

***

#### Using the dApp Interface

Users in permitted jurisdictions can stake and unstake their 0xAssets directly via the ORBT dApp interface.

The staking workflow is as follows:

1. **Connect Wallet:** The user connects a supported Web3 wallet (e.g., MetaMask, Rabby, WalletConnect) to the ORBT app.
2. **Select Asset:** Choose the 0xAsset they wish to stake (0xUSD, 0xETH, or 0xBTC).
3. **Click “Stake”:** Initiate the staking process, which prompts a wallet signature request.
4. **Sign Transaction:** The user signs the transaction to confirm deposit into the staking module.
5. **Receive sTokens:** Upon confirmation, the staked 0xAsset is atomically exchanged for its yield-bearing counterpart (e.g., 0xUSD → s0xUSD).

The UI automatically updates to reflect the staked balance and displays the current APY, total staked amount, and estimated yield accumulation.
