# ORBT Revenue & Yield Model

ORBT’s long-term sustainability is anchored in a **diverse, policy-governed revenue architecture** that transforms protocol activity into predictable, transparent income streams.\
As a [**unified liquidity and settlement layer**](../../orbt-design/unified-liquidity-layer.md), ORBT is designed not only to facilitate capital movement and cross-chain execution but also to **capture and** [**recycle value**](orbt-flywheel-revenue-to-value-loop.md) generated across all ecosystem interactions.

The protocol aggregates yield and revenue through multiple layers - including **real-world settlement flows, money-market spreads, vault premiums, allocator operations, and staking alignment mechanisms**.\
Each source contributes to a consolidated, on-chain treasury cycle that powers **the** [**Immutable Buyback Engine**](immutable-buyback-engine.md), [**governance staking**](../reward-rate.md#how-orbt-staking-rewards-work), and **ecosystem** [**rewards**](../reward-rate.md#how-orbt-staking-rewards-work), ensuring every element of protocol growth reinforces token value and network participation.

By diversifying income across both on-chain and institutional domains, ORBT mitigates dependence on market volatility while maintaining consistent performance and self-sustaining token economics.\
The following sections outline each core revenue stream, its method of accrual, and how these flows converge into ORBT’s [**programmable yield layer**](multi-layer-yield-design.md#programmable-yield-layer) - driving continuous buyback cycles, liquidity strength, and long-term ecosystem stability.
