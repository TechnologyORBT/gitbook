### Overview

**ORBT** is a unified liquidity layer on EVM. It mints liquid, 1:1 tokens called **0xAssets** (e.g., 0xUSD, 0xBTC) that **solve fragmented liquidity** by letting value move simply **across any chain and settle anywhere** in the TradFi & DeFi ecosystem.

**0xAssets** are designed to be fully backed and easy to compose across DeFi. They stay at par through a tight mix of **liquid reserves** and **policy controls** so redemptions are fast and predictable.

ORBT offers **s0xAssets** — the savings versions of 0xAssets. When users hold s0xAssets, the protocol routes the treasury into **pre-funded, intent-based settlements.** These are real transaction flows that earn **allocator fees and routing margins**.&#x20;

ORBT aggregates that revenue and distributes it back to s0xAsset holders as native yield.

**Peg stability** is supported by:

* **High liquid backing** to honor swaps and redemptions at 1:1.
* Liquid Reserves which earns from the native validation services and are liquid 100% of the time.
* **Monetization via pre-funded settlements**, which continuously refills protocol revenues and strengthens the peg over time.
* **On-chain transparency and fast access**, so liquidity returns to the pool within blocks defined by policy controlled allocations, keeping the system responsive under load.
