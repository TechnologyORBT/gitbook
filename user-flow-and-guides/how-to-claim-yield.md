# How to claim yield

Claiming yield allows users to collect the rewards generated from active strategies (Pockets) within the ORBT ecosystem.\
These rewards are derived from lending, liquidity provisioning, or other yield-generating activities executed by the selected strategy, and can be claimed at any time without closing or unstaking the position.

Users in permitted jurisdictions can claim yield via the ORBT dApp interface or through the API.

***

### Using the UI

The user requests to claim rewards via the **“My Pockets”** or **“Rewards”** section of the ORBT app.

Each active Pocket displays accumulated yield in real time, showing both the current profit in 0xAssets and any additional rewards distributed in ORBT tokens.

After reviewing available rewards, the user clicks **“Claim Rewards”**, which triggers a wallet signature request.

Once the user signs the transaction, ORBT executes the claim on-chain, transferring the corresponding reward amounts to the user’s wallet or UPM account.

Upon successful confirmation, the user’s dashboard updates to reflect the new balances and resets the claimed Pocket’s reward counter.
